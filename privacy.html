Політика конфіденційності

Проєкт «Українські новини» — Telegram-канал @News_Ukraine_world_war, це сайт-дзеркало та пов'язані інтеграції автопублікації (Threads, TikTok).

Хто ми

Незалежний новинний проєкт, що публікує оперативні новини України та світу. Контент готується автоматизованим редакційним конвеєром (агрегація публічних новинних джерел + переписування) і публікується в Telegram-каналі, з подальшим автоматичним крос-постингом у Threads та TikTok.

Які дані ми збираємо

Цей сайт (news-ukraine-mirror) — статична сторінка без реєстрації, форм чи облікових записів користувачів. Ми не збираємо особисті дані відвідувачів, не використовуємо власну аналітику й не встановлюємо власних cookie. Хостинг (GitHub Pages) може вести стандартні технічні логи на своєму боці згідно з власною політикою GitHub.

Використання TikTok Content Posting API

Наш застосунок використовує TikTok Content Posting API виключно для автоматичної публікації відео з новинного каналу на ВЛАСНИЙ TikTok-акаунт власника проєкту. Застосунок не збирає, не зберігає й не обробляє дані інших користувачів TikTok, не має доступу до чужих акаунтів і не публікує контент від чийогось імені, крім акаунта власника, який сам надав авторизацію через OAuth.

Токени доступу зберігаються в захищеному сховищі секретів (GitHub Actions Secrets) і не публікуються та не передаються третім особам.

Використання Threads API

Аналогічно — застосунок публікує контент лише на власний акаунт Threads власника проєкту, без доступу до даних інших користувачів.
